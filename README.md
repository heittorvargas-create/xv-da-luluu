# XV da Lulu — Convite Digital

## Como publicar no GitHub Pages (grátis)

1. Crie um repositório novo no GitHub (pode ser público).
2. Envie estes arquivos para a raiz do repositório: `index.html`, `style.css`, `script.js`, e as pastas `images/` e `audio/`.
3. No repositório, vá em **Settings → Pages**.
4. Em "Branch", selecione `main` (ou `master`) e pasta `/root`, depois clique em **Save**.
5. Espere 1–2 minutos. O link do convite vai aparecer ali mesmo, algo como:
   `https://seu-usuario.github.io/nome-do-repositorio/`

Esse é o link que você compartilha — ele abre direto no navegador de quem receber, sem pedir nenhum app.

## Estrutura dos arquivos

- `index.html` — a página em si (convite + lista de presentes)
- `style.css` — todo o visual (cores, fontes, animações)
- `script.js` — toda a interatividade (botões, contador, som, compartilhar)
- `images/` — vazia por enquanto; o convite não depende de nenhuma imagem externa
- `audio/` — vazia por enquanto; o som do mar é gerado por código, sem arquivo
